What it checks

Jev answers four yes/no questions about each change, seeing only the commit message and the diff. The score is how well it tells good changes from problem changes (1.0 = perfect, 0.5 = guessing). Open a row for the exact question.

    How we tested it
    Examples
    184 real commits from four public repos: analyze-stock-kpi, polyfetch-scrape, doc-pipeline-engine and Agents-eval.
    Labels
    59 good and 125 with a problem (30–37 per kind). Most problem examples are a real commit with one problem added; two are real commits that already had one.
    Asked
    Five times per change; the answers agree 97–100% of the time. Jev is called with and without BAML.
    Speed and cost
    Per request as logged. End to end, including start-up, one check took p95 3.15 s without BAML and 2.94 s with it (10 runs each, 2026-09-23). Cost counts input tokens × $0.042 per million (typesafe.ai); no output price is published. Claude's cost is what its CLI reports at list price.
    Firewall
    TypeSafe's firewall blocked 4 changes on 2026-09-23 and none since. Setups are always scored on the changes all of them answered.
    Caveats
    Problems are mostly synthetic. Good labels come from rules plus one audit, not a manual review.
